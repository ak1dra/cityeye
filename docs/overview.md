# CityEye — Overview

## Кратко

CityEye — это MVP платформы совместного управления городской инфраструктурой, где житель, акимат и частный сектор работают не в разных системах, а в одном кейсе.

## Что делает проект сильным

- единая модель обращения для публичной и частной ответственности;
- AI-assisted triage и приоритизация;
- карта, лента и операционные кабинеты внутри одного продукта;
- подтверждение исполнения через фото "до / после";
- shared-case timeline и координационный комментарий между сторонами.

## Demo-логины

- Акимат: `gov@cityeye.kz / CityEye2026`
- Гражданин: `user@cityeye.kz / User2026`
- Бизнес: `business@cityeye.kz / Business2026`

## Что реализовано сейчас

- demo-аккаунты для гражданина, акимата и бизнеса;
- публичные карта и лента;
- создание обращения с адресом, категорией, комментарием и фото;
- кабинет акимата с маршрутизацией и управлением кейсами;
- кабинет частного сектора с исполнением заявок;
- слой совместной работы по shared-case.

## Текущая зрелость

Это hackathon MVP:

- сильный по workflow, UX и модели взаимодействия;
- уже частично усилен на backend;
- ещё не production-ready по auth и permission model.
